### Week 6 Achievements:

* **High Availability System Design:**
  * Mastered the inner workings of Elastic Load Balancers (ELB) and Auto Scaling for automated traffic distribution and dynamically scaling resources based on real-time loads. Successfully provisioned a balanced basic Web App architecture.

* **Monitoring & Logging Proficiency:**
  * Comprehended the distinct differences and synergy between Amazon CloudWatch (performance metrics and visualization) and CloudTrail (user activity logging and auditing). Successfully set up automated metric thresholds to proactively respond to potential system anomalies.

* **Advanced Network Security Implementation:**
  * Differentiated between the stateful architecture of Security Groups at the instance level and the stateless flow of Network ACLs at the subnet layer. Successfully constructed a robust, multi-layered firewall mechanism to shield cloud workloads.

* **Infrastructure Automation (IaC) Adoption & Collaboration:**
  * Acquired a solid baseline in managing infrastructure through code structures utilizing AWS CloudFormation and realized how to reduce packaging overhead using Elastic Beanstalk.
  * Maintained high-velocity team collaboration through the online sync, efficiently debugging common technical issues and structuring the optimal pathway for the next learning sprint.
